# HomeChefHub-Online-Food
A modern online food delivery and cloud kitchen website with user registration, menu browsing, cart, and order flow.
HomeChefHub
HomeChefHub is a simple online food delivery web application built with HTML, CSS, and JavaScript.
It provides a clean user interface for browsing food items, viewing the menu, registering users, and placing orders.

## Features
Modern landing page
Food menu display
Shopping cart
User registration page
Contact and settings pages

## Tech Stack
HTML
CSS
JavaScript
Project Structure
index.html – Home page
CSS/ – Styling files
JS/ – JavaScript logic
image/ – Images used in the website
How to Run
Open the project folder.
Launch index.html in your browser.
